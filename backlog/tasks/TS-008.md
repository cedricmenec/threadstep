# TS-008 | Reprendre là où j'en étais

Status: implemented; OpenSpec PR #21 merged, ADDED capability archived
Priority: high
Dependencies: TS-007 implemented

## User value
Après une interruption ou un changement de sujet, retrouver instantanément l'action volontairement choisie, sans rescanner toutes les listes. La suggestion automatique TS-007 aide à choisir ; TS-008 mémorise le choix humain.

## Scope
- Ajouter à chaque action principale non terminée un contrôle accessible « Garder le fil » / « Reprendre cette action » permettant de la définir comme action en cours.
- Une seule action épinglée pour tout le document. Choisir une autre action remplace la précédente sans modifier les actions elles-mêmes.
- Afficher en haut de l'interface une carte « Je reprends ici » avec sujet, titre, priorité, « Voir dans la liste » et « Ne plus suivre » ; réutiliser le mécanisme accessible de révélation/focus de TS-007.
- Retrouver la même action après rechargement, sans réseau. L'épinglage est identifié par l'ID stable de l'action et du sujet, jamais par le titre ou la position.
- Si l'action suivie est terminée ou supprimée, ou si son sujet est supprimé, supprimer proprement la référence et masquer la carte. L'édition du titre/priorité et le réordonnancement des sujets ne doivent pas rompre le suivi.
- Garder la sélection TS-007 indépendante : demander une suggestion ne change pas l'action suivie.

## Acceptance criteria
- [ ] Choisir une action A affiche une seule carte « Je reprends ici » ; choisir B remplace A.
- [ ] Recharger conserve le suivi ; « Voir dans la liste » révèle et focalise l'action, y compris sur mobile et lorsque le filtre des actions terminées est activé.
- [ ] « Ne plus suivre » efface le suivi sans terminer ni modifier l'action.
- [ ] Terminer ou supprimer l'action suivie, ou supprimer son sujet, nettoie le suivi sans erreur ni référence orpheline.
- [ ] Renommer l'action, changer sa priorité ou réordonner les sujets conserve le suivi et actualise la carte.
- [ ] L'export JSON et l'import restent rétrocompatibles : un ancien export reste importable ; le suivi ne doit pas introduire de changement incompatible dans le schéma documentaire. Documenter explicitement si la préférence de suivi est locale à ce navigateur et exclue des exports.
- [ ] Toutes les commandes sont accessibles au clavier, avec noms français, états annoncés et affichage mobile ; texte utilisateur rendu sans HTML.
- [ ] Tests automatisés couvrent la sélection unique, le remplacement, le rechargement, le nettoyage des références, la compatibilité des exports et l'indépendance de TS-007 ; `npm run check` réussit.
- [ ] Mettre à jour `docs/product/mvp.md` et les tests d'acceptation pour décrire le comportement livré.

## Implementation constraints
- Site statique, sans backend, compte, télémétrie, réseau ni dépendance runtime.
- Utiliser une préférence locale distincte de `threadstep.document.v1` pour la référence suivie, sauf justification documentée ; ne pas changer le format du document JSON existant.
- Ne pas changer les IDs, priorités, drapeaux de complétion ni l'ordre des actions lors du suivi.
- Réutiliser le focus et les composants existants plutôt que créer un second système de navigation.
- Ne pas toucher aux workflows, politiques d'agents ou `docs/factory/` dans l'implémentation produit.

## Out of scope
Plusieurs actions suivies, historique, temps passé, Pomodoro, rappels, notifications, IA dans l'application, synchronisation multi-appareils.

## Assumptions or decisions
- Le suivi est une préférence de ce navigateur, non exportée en JSON. Le document de tâches reste intégralement portable et rétrocompatible.
- Les sous-étapes ne peuvent pas être épinglées dans cette première version.
- Tester le nouveau cycle OPSX sémantique après fusion de sa PR et de cette tâche ; aucun lancement payant n'est autorisé par la création de cette tâche.
