# TS-066 | Harmoniser Overview avec les références Stitch approuvées

## User value
Appliquer une composition visuelle cohérente et responsive à Overview après stabilisation des frontières React.

## Scope
Qualifier les maquettes Overview et obtenir une approbation explicite du sous-ensemble avant toute modification visuelle; réutiliser tokens et composants; conserver les règles canoniques et libellés français.

## Acceptance criteria
- [ ] Approbation Stitch tracée; comparaison à 320/390/430/768/1280 px; contraste, focus et cibles tactiles vérifiés; aucune nouvelle fonctionnalité; CI et recette réelle.
- [ ] `npm run check`, `npm run build` et `npm run verify:build` réussissent, avec CI indépendante sur le SHA final.
- [ ] La recette manuelle desktop et Android est documentée, sans prétendre qu’un test simulé prouve l’accessibilité réelle.

## Implementation constraints
- Respecter `AGENTS.md`, les spécifications `openspec/specs/` et les frontières DOM React/vanilla déjà livrées.
- Préserver routes hash, IndexedDB/Dexie, identité d’espace, OTP, consentement, sauvegarde et restauration.
- `automation: manual` : aucune exécution payante ou fusion de code autorisée par la seule création de cette fiche.

## Out of scope
Reprise des maquettes non approuvées, nouveaux comportements Cloud, refonte globale du produit.

## Assumptions or decisions
Bloquant : les références Stitch spécifiques à Overview devront être examinées et approuvées explicitement avant le plan d’implémentation.

## Manual acceptance
Tester la page Overview sur desktop et Chrome Android : navigation, rafraîchissement, clavier, tactile, focus et scroll, états de chargement, changement d’espace et synchronisation de test sans purge.

## Post-sync review
Contrôler le diff, la CI indépendante, l’archivage OpenSpec, la publication Pages et consigner les limites de recette.
