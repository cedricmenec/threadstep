# TS-003 | Safe autonomous waves (future)

Status: backlog, not authorized for autonomous execution.

## Scope
Separate reusable factory from application; add deterministic task readiness, dependency tracking, retries, spend limits, observability, protected CI gates and only then safe auto-merge.

## Acceptance criteria
- Dry-run selects correct ready tasks.
- Paid execution requires explicit bounded authorization per wave.
- One in-flight development PR at a time until conflicts are managed.
- Retries are idempotent and resume from durable remote branch state.
- Auto-merge is impossible without independent required checks and branch protections.
- Notify user via GitHub issue/PR status on completed, failed or blocked wave.
