# TS-006 | Masquer temporairement les étapes terminées

Status: implemented; PR #12 merged
Priority: normal
Dependencies: TS-001
Source: factory GitHub App smoke test, 2026-10-14

## User value

As a ThreadStep user, I want to hide completed actions temporarily so that I can focus on unfinished work without deleting any history.

## Scope

- Add one clearly labeled, keyboard- and touch-accessible French toggle near the list of subjects: « Masquer les étapes terminées » / « Afficher les étapes terminées » (or an equivalently clear checkbox).
- Default to showing all actions and substeps on page load, as today.
- When enabled, hide completed top-level actions and completed substeps from the displayed lists, without modifying or deleting any document data.
- If a completed parent has unfinished substeps, keep the parent visible as context so its unfinished substeps remain reachable; completed children of that parent stay hidden.
- When disabled, restore the full view, preserving priority order and nesting.
- The toggle is view-only UI state; do not persist its setting or change the existing JSON format.

## Acceptance criteria

- [ ] The default view shows completed and unfinished actions as before.
- [ ] Enabling the toggle hides completed actions and completed substeps, except a completed parent with at least one unfinished substep, which remains visible with those unfinished substeps.
- [ ] Disabling the toggle shows all items again in their original hierarchy and priority order.
- [ ] The counter of unfinished steps stays unchanged by the toggle.
- [ ] Toggling never changes item IDs, titles, priorities, done flags, parent IDs, subject order, localStorage contents or JSON export.
- [ ] The toggle has a clear French accessible label, works with keyboard and touch, and remains usable on mobile.
- [ ] Add focused tests for the visibility decision (prefer a pure helper in `site/core.js`), including a completed parent with an unfinished child; `npm run check` passes.

## Implementation constraints

- Keep changes small and limited to `site/` and `tests/` as necessary.
- Preserve the current `threadstep.document.v1` schema and GitHub Pages compatibility.
- Use safe text nodes; do not add a backend, dependencies or network calls.
- Do not change GitHub workflows, credentials, AGENTS.md, OpenCode/OpenSpec configuration or other protected files.

## Out of scope

- Persistent filter preferences, search, per-subject filters, bulk completion, deleting or archiving completed tasks, and deeper nesting.

## Assumptions or decisions

- This is a temporary display filter, reset on reload.
- A completed parent is displayed when needed to keep an unfinished child visible.
- Preparing this task is not authorization to call OpenRouter or launch the workflow.
