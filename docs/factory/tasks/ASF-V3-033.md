## Critères de sortie
1. Une seule identité Controller V3 (App 5361227) capable d'écrire les refs protégés, et aucun second chemin CAS caché. Les tests de droits réels sont des preuves distinctes du contrôle des rulesets.
2. Une intention propriétaire est liée au run GitHub exact, au commit `main`, aux six inputs canoniques et au hash de candidats ; aucune entrée d'un modèle/PR non fiable n'est mandat.
3. Le premier bootstrap ne peut écrire qu'une genèse canonique avec preuve de non-existence, et refuse les retours ambigus ; un registre existant ne doit jamais être remplacé.
4. Quota 1..10, `maxPaidRetries=0`, mutex job-level `threadstep-paid-development-v1` avec `cancel-in-progress:false`, pas de nouvelle dépense après erreur ambiguë.
5. RELEASE seulement après vérifications externes PR / merge / CI / `main` / Pages ; sinon arrêt, QUARANTINE ou investigation selon l'état prouvé.
6. CI Node, actionlint, OpenSpec au SHA exact, preuve GitHub de qualification sans LLM et revue de sécurité documentée.
7. Toute activation de secret, changement de permissions/rulesets, bootstrap live, fusion de workflow privilégié et premier appel payant exige une autorisation propriétaire distincte.
