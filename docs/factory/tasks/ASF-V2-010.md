## Critères d'acceptation et vérification

- [x] Deux livraisons => une PR documentaire, zéro livraison => aucune PR. Vérifié par `tests/asf-archive.test.mjs` : deux livraisons `verified` produisent exactement une PR (`pullRequest` non nul, deux déplacements) ; zéro livraison vérifiée produit `pullRequest: null` et aucun déplacement.
- [x] Après réussite de la première et échec de la seconde, seule la première peut être archivée. Vérifié : livraison `verified` + livraison `failed`/`unknown` ⇒ `moves` contient uniquement la première, la seconde reste bloquée avec motif.
- [x] Archive pending ne rend jamais la tâche réexécutable, et les règles de main ne sont jamais contournées. Vérifié : `evaluateArchiveOutcome` sur PR ouverte/échouée renvoie `archive_pending` pour chaque déplacement, tandis que `toExecutionEvidence` projette la livraison comme `verified` (jamais redispatchée) ; `runArchiveAutoMerge` conserve `Protect Main`, le check `check` et `--match-head-commit`, sans `--admin`.
- [x] Tests de non-régression et npm run check passent. Exécuté localement : `npm run check` → `npm test` 265 tests réussis, puis `backlog:check` (11 actifs, 0 archivé), puis `node --check site/core.js` et `node --check site/app.js` (aucun workflow modifié, donc Actionlint non requis).
