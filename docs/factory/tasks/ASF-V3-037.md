# ASF-V3-037 : essai hors ligne d'intention de genèse durable

Statut : PR de tests non opérationnels, empilée sur ASF-V3-036/#179. Automation: manual. Risque : high (validation de bootstrap et anti-retry futurs).

## But
Valider avec deux processus simulés et un faux stockage transactionnel que l'intention `BEGIN_CREATE_ATTEMPT` est enregistrée durablement **avant** l'envoi d'une création Git fictive, et qu'aucune relance n'est déclenchée après perte de réponse, redémarrage ou concurrence. Ce test ne prétend pas démontrer l'atomicité REST réelle de GitHub.

## Acceptation
- [x] Simulation sans aucune requête GitHub, secret, App token, LLM ou écriture Git.
- [x] Stockage synthétique partagé à version CAS, snapshots JSON relus depuis un autre processus logique.
- [x] Deux runners observant la même révision : au plus un enregistrement d'intention.
- [x] Réponse CREATE perdue : même après redémarrage, pas de second CREATE ; QUARANTINED sans auto-retry.
- [x] Après ACK puis readback, aucune autorité `canCreate`, `canSpend` ou `canRetry`.
- [x] Corruption d'un compteur, du run owner ou de l'historique rejetée.
- [ ] CI Node, actionlint et OpenSpec vertes sur SHA exact.
- [ ] Qualification G1, tests négatifs par tokens GitHub Apps et preuve de stockage d'intention réellement durable avant G2.

## Non-objectifs
Aucun writer privilégié, workflow modifié, ref global créé, règles de branches modifiées, dispatch, OpenRouter, dépense ou fusion sensible. La simulation ne garantit pas l'exécution exactly-once en présence de crash réseau réel ; G2 et G3 nécessitent des tests d'intégration dédiés.
